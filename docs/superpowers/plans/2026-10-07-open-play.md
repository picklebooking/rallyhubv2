# Open Play Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `CourtBooking.isOpenPlay` real. Open Play bookings get a capacity (default 4, booker included), a roster of immediately-confirmed seats, a non-guessable join link, an optional public listing on an anonymous cross-venue discovery endpoint, and leave/cancel rules with a 24-hour cutoff. The web gets a `/open-play` discovery page and a join-link page.

**Architecture:** One additive Prisma migration: three Open Play columns on `CourtBooking` and a new `OpenPlaySeat` table with `@@unique([bookingId, userId])`. `CourtBookModule` handles create-time opt-in. A new sibling `OpenPlayModule` (thin controller, service, repository) handles discovery, join, leave, cancel, enable-on-existing, visibility, and a management read. Every seat-changing operation runs inside a Prisma interactive `$transaction` that starts by row-locking the booking with a conditional `updateMany`. Authorization reads the venue/tenant from the booking itself and checks `TenantMember` for staff. It never trusts request context.

**Tech Stack:** NestJS 11, Prisma 7 (`prisma-client` generator, `PrismaPg` adapter), class-validator / class-transformer DTOs, Jest (`ts-jest`, `@jest/globals`), Better Auth via `@thallesp/nestjs-better-auth` (`@Session`, `@AllowAnonymous`, `@OptionalAuth`), `@workspace/shared` type-only contracts, Next.js 16 App Router, TanStack Query v5, React Hook Form + Zod v4, `@workspace/ui` shadcn primitives.

**Spec:** `docs/superpowers/specs/2026-10-07-open-play-design.md`

## Global Constraints

- **Never run `npx prisma migrate dev`, `prisma migrate deploy`, `prisma db push`, `npm run db:generate`/`prisma generate`, or `npm install`.** Task 1 edits `schema.prisma`, validates it, and STOPS for a human to create, review, and apply the migration and regenerate the client. (`npm run build -w api` and `npm run dev -w api` run `prisma generate` as part of their own scripts. That's expected; just don't invoke generation directly.)
- **Commit messages must contain no AI attribution.** No `Co-Authored-By: Claude…`, no 🤖 line, no "Generated with" line. This repo forbids them regardless of any harness default.
- Default capacity is `4`, and capacity includes the booker's seat. Capacity must be a whole number from 1 to 64 (`@IsInt() @Min(1) @Max(MAX_OPEN_PLAY_CAPACITY)`, `MAX_OPEN_PLAY_CAPACITY = 64`). The web Zod schema mirrors the same bounds.
- "Viewable" and "joinable" are defined once, by `openPlayViewableWhere()` / `openPlayJoinableWhere(now)` in `open-play.repository.ts` (Task 5). Discovery, the token routes, join-by-id, and the `joinSeat` lock all use them. Don't re-spell those preconditions inline anywhere.
- `CourtSchedule.isActive` is nullable. Never filter schedules with `NOT: { isActive: false }` (a NULL row would silently stop matching). Use the non-nullable `isVacant`.
- The leave/cancel cutoff is exactly 24 hours (`24 * 60 * 60 * 1000` ms) before `bookDate`. "Until 24 hours before" means allowed while `now <= bookDate − 24h`.
- Discovery and by-token responses must never contain `userEmail`, `userId`, `referenceId`, `isPaid`, `totalPrice`, `openPlayJoinToken`/`joinToken`, or `tenantId`.
- AC-05 (cost sharing) is deferred. Don't touch `totalPrice`/`isPaid` semantics, and add no per-seat pricing or payment fields.
- Read the booking's venue and tenant from the booking (`booking.venueId`, `booking.court.venue.tenantId`). Never use `@CurrentVenue()`/`@CurrentTenant()` in `OpenPlayController`.
- Match repo conventions: thin controller → service → repository; JSDoc on every public method (`@param`/`@returns`/`@throws`); class-validator DTOs; no `any`; explicit return types; type-only `@workspace/shared` imports.
- Frontend: thin route files, `@workspace/ui` primitives only (no `shadcn add`), shared theme tokens (no ad hoc tints like `bg-muted/30`), both light and dark mode, and explicit `isPending`/error/empty states for every query.
- TDD for all API work: failing test → watch it fail → minimal implementation → watch it pass → commit.

## Review Focus

These are inputs the spec implies but never spells out. Each one has a test pinned in its owning task:

1. **Malformed discovery query strings** (`page=abc`, `pageSize=0`, `pageSize=51`, `venueId=` empty, `from=yesterday`) should return 400 from validation, never a 500 from Prisma. Pinned in Task 7, `open-play.dto.spec.ts`.
2. **A page past the last page** (`page=99` with 3 results) should return `items: []` with the true `total`, not an error. Pinned in Task 6, `list` tests.
3. **The booker opening their own join link and pressing Join** should get a 409 "already have a seat", never a second seat. Pinned in Task 6, `joinByToken` tests.
4. **The join link of a cancelled booking, or of a booking at a non-ACTIVE venue, or whose booker was deleted** should show "not found" (404) on both the view and the join-by-token route, not a stale joinable card. The service side is pinned in Task 6 (`getByToken`/`joinByToken` 404 when the viewable read returns null); the actual exclusion is pinned against a real DB in Task 8.
5. **A user who never joined calling leave** should get a 404 "no seat", not a silent 204. Pinned in Task 6, `leave` tests.
6. **A capacity of 65 or 2147483648** should be a 400 from validation, never a Postgres `Int` overflow 500. Pinned in Tasks 4 and 7 DTO specs.
7. **A Prisma transaction timeout or deadlock under load** should be a retry-able 409, never a raw 500. Pinned in Task 5 (`P2028`/deadlock → `BUSY`) and Task 6 (`BUSY` → 409).

```ts
/** Seats (including the booker's) when the creator gives no capacity. */
export const DEFAULT_OPEN_PLAY_CAPACITY = 4;

/**
 * Product cap on capacity. Keeps DTO input far below Postgres `Int` range
 * (an unbounded value would overflow the column and surface as a 500).
 * The web Zod schema mirrors this value.
 */
export const MAX_OPEN_PLAY_CAPACITY = 64;

/** Discovery pagination defaults. */
export const DEFAULT_OPEN_PLAY_PAGE_SIZE = 20;
export const MAX_OPEN_PLAY_PAGE_SIZE = 50;

/** Leaving / cancelling closes this long before the start time. */
export const OPEN_PLAY_CUTOFF_MS = 24 * 60 * 60 * 1000;

/**
 * Whether the booking's start time has been reached.
 *
 * @param   {Date}    bookDate The booking's start time.
 * @param   {Date}    now      The current time.
 * @returns {boolean}          `true` once `now >= bookDate`.
 */
export function hasStarted(bookDate: Date, now: Date): boolean {
  return now.getTime() >= bookDate.getTime();
}

/**
 * Whether `now` is inside the 24-hour window before start. Exactly 24h
 * before start is still outside the window ("until 24 hours before").
 *
 * @param   {Date}    bookDate The booking's start time.
 * @param   {Date}    now      The current time.
 * @returns {boolean}          `true` when `now > bookDate - 24h`.
 */
export function isInsideCutoff(bookDate: Date, now: Date): boolean {
  return now.getTime() > bookDate.getTime() - OPEN_PLAY_CUTOFF_MS;
}

/**
 * The earliest start time that is still outside the cutoff at `now`, for
 * use as a `bookDate >= …` database filter.
 *
 * @param   {Date} now The current time.
 * @returns {Date}     `now + 24h`.
 */
export function latestLeaveableStart(now: Date): Date {
  return new Date(now.getTime() + OPEN_PLAY_CUTOFF_MS);
}

/**
 * Whether confirmed seats have reached capacity.
 *
 * @param   {number}  confirmedSeats Seats currently held (booker included).
 * @param   {number}  capacity       Total seats.
 * @returns {boolean}                `true` when no seat is left.
 */
export function isFull(confirmedSeats: number, capacity: number): boolean {
  return confirmedSeats >= capacity;
}
```

```ts
import { randomBytes } from 'node:crypto';
import { Injectable } from '@nestjs/common';

/** 24 random bytes -> 32 base64url chars (192 bits). */
const TOKEN_BYTES = 24;

@Injectable()
export class OpenPlayTokenHelper {
  /**
   * Generates a non-guessable Open Play join token.
   *
   * Unlike `PNRHelper`, there is no regenerate-until-unique loop: at 192
   * bits a collision is not a practical concern, and
   * `CourtBooking.openPlayJoinToken @unique` is the DB backstop.
   *
   * @returns {string} A 32-character base64url token.
   */
  public generate(): string {
    return randomBytes(TOKEN_BYTES).toString('base64url');
  }
}
```

  - Methods: `listPublic(filter): Promise<{ records: OpenPlayListingRecord[]; total: number }>`, `findById(id): Promise<OpenPlayBookingRecord | null>` (unfiltered, for management routes), `findViewableById(id): Promise<OpenPlayBookingRecord | null>`, `findViewableByToken(token): Promise<OpenPlayBookingRecord | null>`, `findSeat(bookingId, userId): Promise<{ isBooker: boolean } | null>`, `findRoster(bookingId): Promise<OpenPlayRosterRecord[]>`, `hasVenueStaffMembership(userId, tenantId, venueId): Promise<boolean>`, `joinSeat({ bookingId, userId, now, requirePublic }): Promise<JoinSeatOutcome>`, `leaveSeat({ bookingId, userId, now }): Promise<LeaveSeatOutcome>`, `cancelBooking({ bookingId, bookerId, now }): Promise<CancelOutcome>`, `enableOpenPlay({ bookingId, now, capacity, isPublic, token }): Promise<EnableOutcome>`, `setVisibility(bookingId, isPublic): Promise<boolean>`

Three rules this repository enforces, each pinned by a test below:

1. **One definition of viewable/joinable.** Discovery, `findViewableBy*`, and `joinSeat` all build their `where` from the exported builders, so a venue that isn't `ACTIVE`, a cancelled booking, or a booking whose booker was deleted can't be listed, viewed, or joined through any path.
2. **No relation `_count`.** Prisma compiles a `_count` select to an aggregate over the whole `OpenPlaySeat` table, which `LIMIT` can't be pushed into. Seat counts come from `openPlaySeat.groupBy` scoped to the page's ids (discovery) or `openPlaySeat.count({ where: { bookingId } })` (single reads and the lock).
3. **No raw Prisma errors from seat-mutating methods.** Every interactive transaction passes `OPEN_PLAY_TX_OPTIONS` and goes through `runSeatTransaction`, which maps `P2002`/`P2003` to the method's own outcome, maps timeouts/deadlocks to `BUSY`, and rethrows anything else.

```ts
export const OPEN_PLAY_TX_OPTIONS = { maxWait: 5_000, timeout: 10_000 } as const;

 * columns set, and a booker who still exists. Scalar-only on purpose: this
 * is what goes into the lock's `updateMany` `where`, which must stay a

export function openPlayLiveScalars(): Prisma.CourtBookingWhereInput {
  return {
    isOpenPlay: true,
    isActive: true,
    openPlayCapacity: { not: null },
    openPlayJoinToken: { not: null },
    userId: { not: null },
  };

export function openPlayViewableWhere(): Prisma.CourtBookingWhereInput {
  return {

/**
 * Whether an error from an interactive transaction is a transient
 * contention failure worth retrying: P2028 (transaction timed out / closed),
 * P2034 (write conflict or deadlock), or a raw Postgres deadlock (40P01)
 * surfaced by the pg driver adapter without a Prisma code.
 *
 * @param   {unknown} error The caught error.
 * @returns {boolean}
 */
export function isRetryableTransactionError(error: unknown): boolean {
  if (
    error instanceof Prisma.PrismaClientKnownRequestError &&
    (error.code === 'P2028' || error.code === 'P2034')
  ) {
    return true;
  }
  const message = error instanceof Error ? error.message : String(error);
  return /40P01|deadlock detected/i.test(message);

   */
  async hasVenueStaffMembership(
    userId: string,
    tenantId: string,
    venueId: string,
  ): Promise<boolean> {
    const member = await this.prisma.db.tenantMember.findFirst({
      where: {
        userId,
        tenantId,
        role: { in: ['OWNER', 'STAFF'] },
        OR: [{ venueId: null }, { venueId }],
      },
      select: { id: true },
    });
    return member !== null;
  }

  /**
   * Reserves a seat. Concurrency-safe: the conditional `updateMany` takes a
   * row lock on the booking (held until commit), so concurrent joins on one
   * booking serialize, and under READ COMMITTED each later statement sees
   * seats committed by the previous lock holder. The lock's `where` is
   * scalar-only; the full joinable builder (venue status included) is
   * re-checked by a `findFirst` right after, while the row is locked. The
   * capacity check lives here, not in the service, because it must run
   * under that lock.
   *
   * @param   {{ bookingId: string; userId: string; now: Date; requirePublic: boolean }} args
   * @returns {Promise<JoinSeatOutcome>}
   */
  async joinSeat(args: {
    bookingId: string;
    userId: string;
    now: Date;
    requirePublic: boolean;
  }): Promise<JoinSeatOutcome> {
    const { bookingId, userId, now, requirePublic } = args;
    const publicOnly = requirePublic ? { isOpenPlayPublic: true } : {};

    return this.runSeatTransaction<JoinSeatOutcome>(
      async (tx) => {
        const locked = await tx.courtBooking.updateMany({
          where: {
            id: bookingId,
            ...openPlayLiveScalars(),
            bookDate: { gt: now },
            ...publicOnly,
          },
          data: { updatedAt: now },
        });
        if (locked.count === 0) return { kind: 'NOT_JOINABLE' } as const;

        const booking = await tx.courtBooking.findFirst({
          where: { id: bookingId, ...openPlayJoinableWhere(now), ...publicOnly },
          select: { openPlayCapacity: true },
        });
        if (booking === null || booking.openPlayCapacity === null) {
          return { kind: 'NOT_JOINABLE' } as const;
        }

        const existing = await tx.openPlaySeat.findUnique({
          where: { bookingId_userId: { bookingId, userId } },
          select: { id: true },
        });
        if (existing) return { kind: 'ALREADY_SEATED' } as const;

        const capacity = booking.openPlayCapacity;
        const confirmed = await tx.openPlaySeat.count({ where: { bookingId } });
        if (isFull(confirmed, capacity)) return { kind: 'FULL' } as const;

        await tx.openPlaySeat.create({
          data: { bookingId, userId, isBooker: false },
        });
        return {
          kind: 'JOINED',
          confirmedSeats: confirmed + 1,
          capacity,
        } as const;
      },
      { P2002: { kind: 'ALREADY_SEATED' }, P2003: { kind: 'NOT_JOINABLE' } },
    );
  }

  /**
   * Releases a non-booker seat, only while the booking starts at or after
   * `now + 24h`. Locks the booking like `joinSeat`.
   *
   * @param   {{ bookingId: string; userId: string; now: Date }} args
   * @returns {Promise<LeaveSeatOutcome>}
   */
  async leaveSeat(args: {
    bookingId: string;
    userId: string;
    now: Date;
  }): Promise<LeaveSeatOutcome> {
    const { bookingId, userId, now } = args;

    return this.runSeatTransaction<LeaveSeatOutcome>(async (tx) => {
      const locked = await tx.courtBooking.updateMany({
        where: {
          id: bookingId,
          isOpenPlay: true,
          isActive: true,
          bookDate: { gte: latestLeaveableStart(now) },
        },
        data: { updatedAt: now },
      });
      if (locked.count === 0) return { kind: 'NOT_LEAVABLE' } as const;

      const deleted = await tx.openPlaySeat.deleteMany({
        where: { bookingId, userId, isBooker: false },
      });
      return deleted.count > 0
        ? ({ kind: 'LEFT' } as const)
        : ({ kind: 'NO_SEAT' } as const);
    });
  }

  /**
   * Soft-cancels an Open Play booking and frees its schedule rows
   * (`isActive: false, isVacant: true`). Inside the 24h window this is
   * refused while any non-booker seat exists. Locks the booking like
   * `joinSeat`, so it cannot race a join.
   *
   * @param   {{ bookingId: string; bookerId: string; now: Date }} args
   * @returns {Promise<CancelOutcome>}
   */
  async cancelBooking(args: {
    bookingId: string;
    bookerId: string;
    now: Date;
  }): Promise<CancelOutcome> {
    const { bookingId, bookerId, now } = args;

    return this.runSeatTransaction<CancelOutcome>(async (tx) => {
      const locked = await tx.courtBooking.updateMany({
        where: {
          id: bookingId,
          isOpenPlay: true,
          isActive: true,
          userId: bookerId,
          bookDate: { gt: now },
        },
        data: { updatedAt: now },
      });
      if (locked.count === 0) return { kind: 'NOT_CANCELLABLE' } as const;

      const booking = await tx.courtBooking.findUniqueOrThrow({
        where: { id: bookingId },
        select: { bookDate: true, courtId: true, referenceId: true },
      });

      if (isInsideCutoff(booking.bookDate, now)) {
        const others = await tx.openPlaySeat.count({
          where: { bookingId, isBooker: false },
        });
        if (others > 0) return { kind: 'OTHER_PLAYERS' } as const;
      }

      await tx.courtBooking.update({
        where: { id: bookingId },
        data: { isActive: false },
      });
      await tx.courtSchedule.updateMany({
        where: { referenceId: booking.referenceId, courtId: booking.courtId },
        data: { isActive: false, isVacant: true },
      });
      return { kind: 'CANCELLED' } as const;
    });
  }

  /**
   * Turns an existing private booking into Open Play and seats its booker.
   *
   * @param   {{ bookingId: string; now: Date; capacity: number; isPublic: boolean; token: string }} args
   * @returns {Promise<EnableOutcome>}
   */
  async enableOpenPlay(args: {
    bookingId: string;
    now: Date;
    capacity: number;
    isPublic: boolean;
    token: string;
  }): Promise<EnableOutcome> {
    const { bookingId, now, capacity, isPublic, token } = args;

    return this.runSeatTransaction<EnableOutcome>(
      async (tx) => {
        const locked = await tx.courtBooking.updateMany({
          where: {
            id: bookingId,
            isOpenPlay: false,
            isActive: true,
            userId: { not: null },
            bookDate: { gt: now },
          },
          data: { updatedAt: now },
        });
        if (locked.count === 0) return { kind: 'NOT_ENABLEABLE' } as const;

        const { userId } = await tx.courtBooking.findUniqueOrThrow({
          where: { id: bookingId },
          select: { userId: true },
        });
        if (userId === null) return { kind: 'NOT_ENABLEABLE' } as const;

        await tx.courtBooking.update({
          where: { id: bookingId },
          data: {
            isOpenPlay: true,
            openPlayCapacity: capacity,
            isOpenPlayPublic: isPublic,
            openPlayJoinToken: token,
          },
        });
        await tx.openPlaySeat.create({
          data: { bookingId, userId, isBooker: true },
        });
        return { kind: 'ENABLED' } as const;
      },
      { P2002: { kind: 'NOT_ENABLEABLE' }, P2003: { kind: 'NOT_ENABLEABLE' } },
    );
  }

  /**
   * Sets the public-listing flag on an active Open Play booking.
   *
   * @param   {string}  bookingId The booking id.
   * @param   {boolean} isPublic  The new flag.
   * @returns {Promise<boolean>}  `false` if the booking no longer qualifies.
   */
  async setVisibility(bookingId: string, isPublic: boolean): Promise<boolean> {
    const result = await this.prisma.db.courtBooking.updateMany({
      where: { id: bookingId, isOpenPlay: true, isActive: true },
      data: { isOpenPlayPublic: isPublic },
    });
    return result.count > 0;
  }

  /**
   * Runs one interactive seat transaction with explicit bounds and turns
   * known Prisma/Postgres failures into outcomes, so none surfaces as a raw
   * 500: `P2002`/`P2003` map to the caller's outcome (when given),
   * timeouts/conflicts/deadlocks map to `BUSY`, anything else is rethrown.
   *
   * @param   {(tx: Prisma.TransactionClient) => Promise<T>} work The transaction body.
   * @param   {{ P2002?: T; P2003?: T }} onConstraint Outcomes for constraint violations.
   * @returns {Promise<T | BusyOutcome>}
   * @throws  {unknown} Any error that isn't mapped.
   */
  private async runSeatTransaction<T extends { kind: string }>(
    work: (tx: Prisma.TransactionClient) => Promise<T>,
    onConstraint: { P2002?: T; P2003?: T } = {},
  ): Promise<T | BusyOutcome> {
    try {
      return await this.prisma.db.$transaction(work, OPEN_PLAY_TX_OPTIONS);
    } catch (error) {
      if (error instanceof Prisma.PrismaClientKnownRequestError) {
        if (error.code === 'P2002' && onConstraint.P2002) return onConstraint.P2002;
        if (error.code === 'P2003' && onConstraint.P2003) return onConstraint.P2003;
      }
      if (isRetryableTransactionError(error)) return { kind: 'BUSY' };
      throw error;
    }
  }

  /** Seat counts for a page of bookings, in one `groupBy` scoped to those ids. */
  private async countSeats(bookingIds: string[]): Promise<Map<string, number>> {
    if (bookingIds.length === 0) return new Map();
    const groups = await this.prisma.db.openPlaySeat.groupBy({
      by: ['bookingId'],
      where: { bookingId: { in: bookingIds } },
      _count: { _all: true },
    });
    return new Map(groups.map((group) => [group.bookingId, group._count._all]));
  }

  /** Attaches `confirmedSeats` to a single booking row with an index-scoped count. */
  private async withSeatCount(
    row: BookingRow | null,
  ): Promise<OpenPlayBookingRecord | null> {
    if (row === null) return null;
    const confirmedSeats = await this.prisma.db.openPlaySeat.count({
      where: { bookingId: row.id },
    });
    return { ...row, confirmedSeats };
  }
}
```

```ts
import {
  ConflictException,
  ForbiddenException,
  Injectable,
  NotFoundException,
} from '@nestjs/common';
import type {
  JoinOpenPlayResponse,
  ListOpenPlayResponse,
  OpenPlayByTokenResponse,
  OpenPlayListing,
  OpenPlayManageResponse,
} from '@workspace/shared';
import { ErrorConstant } from '../constants/error-code.constant';
import { OpenPlayTokenHelper } from '../helper/open-play-token.helper';
import type {
  EnableOpenPlayDto,
  ListOpenPlayQueryDto,
  SetOpenPlayVisibilityDto,
} from './dto';
import {
  OpenPlayRepository,
  type OpenPlayBookingRecord,
  type OpenPlayListingRecord,
} from './open-play.repository';
import {
  DEFAULT_OPEN_PLAY_CAPACITY,
  DEFAULT_OPEN_PLAY_PAGE_SIZE,
  hasStarted,
  isFull,
  isInsideCutoff,
} from './open-play.rules';

const MSG = ErrorConstant.OPEN_PLAY_MESSAGES;

/** A booking whose Open Play invariant holds (flag, capacity, token all set). */
type OpenPlayRecord = OpenPlayBookingRecord & {
  isOpenPlay: true;
  openPlayCapacity: number;
  openPlayJoinToken: string;
};

@Injectable()
export class OpenPlayService {
  /**
   * Constructs the `OpenPlayService`.
   *
   * @param {OpenPlayRepository}  repository  Open Play data access.
   * @param {OpenPlayTokenHelper} tokenHelper Join-token generator.
   */
  constructor(
    private readonly repository: OpenPlayRepository,
    private readonly tokenHelper: OpenPlayTokenHelper,
  ) {}

  /**
   * Lists publicly visible Open Play games (AC-07).
   *
   * @param   {ListOpenPlayQueryDto}          query Filters and page.
   * @returns {Promise<ListOpenPlayResponse>}
   */
  async list(query: ListOpenPlayQueryDto): Promise<ListOpenPlayResponse> {
    const page = query.page ?? 1;
    const pageSize = query.pageSize ?? DEFAULT_OPEN_PLAY_PAGE_SIZE;
    const { records, total } = await this.repository.listPublic({
      now: new Date(),
      venueId: query.venueId,
      from: query.from ? new Date(query.from) : undefined,
      to: query.to ? new Date(query.to) : undefined,
      skip: (page - 1) * pageSize,
      take: pageSize,
    });
    return {
      items: records.map((record) => this.toListing(record)),
      page,
      pageSize,
      total,
    };
  }

  /**
   * Views a game via its join link, regardless of public visibility.
   *
   * @param   {string}      token        The join token.
   * @param   {string|null} viewerUserId Signed-in user id, or `null`.
   * @returns {Promise<OpenPlayByTokenResponse>}
   * @throws  {NotFoundException} Unknown token, or not viewable (cancelled,
   *          venue not ACTIVE, booker deleted; see `openPlayViewableWhere`).
   */
  async getByToken(
    token: string,
    viewerUserId: string | null,
  ): Promise<OpenPlayByTokenResponse> {
    const booking = await this.repository.findViewableByToken(token);
    if (!this.isOpenPlay(booking)) throw new NotFoundException(MSG.NOT_FOUND);
    const seat = viewerUserId
      ? await this.repository.findSeat(booking.id, viewerUserId)
      : null;
    return {
      listing: this.toListing(booking),
      isPublic: booking.isOpenPlayPublic,
      viewer: viewerUserId
        ? { hasSeat: seat !== null, isBooker: seat?.isBooker ?? false }
        : null,
    };
  }

  /**
   * Joins via the join link (AC-04), regardless of visibility.
   *
   * @param   {string} token  The join token.
   * @param   {string} userId The signed-in user.
   * @returns {Promise<JoinOpenPlayResponse>}
   * @throws  {NotFoundException} Unknown token or not viewable (incl. cancelled).
   * @throws  {ConflictException} Started, full, already seated, busy, or lost race.
   */
  async joinByToken(token: string, userId: string): Promise<JoinOpenPlayResponse> {
    const booking = await this.repository.findViewableByToken(token);
    if (!this.isOpenPlay(booking)) throw new NotFoundException(MSG.NOT_FOUND);
    return this.join(booking, userId, false);
  }

  /**
   * Joins from the public listing (AC-04). Unknown, non-viewable, and
   * non-listed games all get the identical 404, so a non-listed booking's
   * existence never leaks through this route (the one route where the
   * "same 404" guarantee applies; see the spec's Error Handling).
   *
   * @param   {string} bookingId The booking id.
   * @param   {string} userId    The signed-in user.
   * @returns {Promise<JoinOpenPlayResponse>}
   * @throws  {NotFoundException} Unknown, not viewable, or not public.
   * @throws  {ConflictException} Started, full, already seated, busy, or lost race.
   */
  async joinPublic(bookingId: string, userId: string): Promise<JoinOpenPlayResponse> {
    const booking = await this.repository.findViewableById(bookingId);
    if (!this.isOpenPlay(booking) || !booking.isOpenPlayPublic) {
      throw new NotFoundException(MSG.NOT_FOUND);
    }
    return this.join(booking, userId, true);
  }

  /**
   * Releases the caller's (non-booker) seat, until 24h before start (AC-06).
   *
   * @param   {string} bookingId The booking id.
   * @param   {string} userId    The signed-in user.
   * @returns {Promise<void>}
   * @throws  {NotFoundException} Unknown / not Open Play / no seat.
   * @throws  {ConflictException} Cancelled, booker, inside cutoff, or lost race.
   */
  async leave(bookingId: string, userId: string): Promise<void> {
    const booking = await this.loadOpenPlay(bookingId);
    if (booking.isActive !== true) throw new ConflictException(MSG.INACTIVE);

    const seat = await this.repository.findSeat(bookingId, userId);
    if (!seat) throw new NotFoundException(MSG.NO_SEAT);
    if (seat.isBooker) throw new ConflictException(MSG.BOOKER_CANNOT_LEAVE);

    const now = new Date();
    if (isInsideCutoff(booking.bookDate, now)) {
      throw new ConflictException(MSG.LEAVE_CUTOFF);
    }

    const outcome = await this.repository.leaveSeat({ bookingId, userId, now });
    if (outcome.kind === 'NO_SEAT') throw new NotFoundException(MSG.NO_SEAT);
    if (outcome.kind === 'NOT_LEAVABLE') {
      throw new ConflictException(MSG.NO_LONGER_AVAILABLE);
    }
    if (outcome.kind === 'BUSY') throw new ConflictException(MSG.BUSY);
  }

  /**
   * Cancels the whole game; booker only (AC-06).
   *
   * @param   {string} bookingId The booking id.
   * @param   {string} userId    The signed-in user.
   * @returns {Promise<void>}
   * @throws  {NotFoundException}  Unknown / not Open Play.
   * @throws  {ForbiddenException} Caller is not the booker.
   * @throws  {ConflictException}  Cancelled, started, other players inside cutoff, or lost race.
   */
  async cancel(bookingId: string, userId: string): Promise<void> {
    const booking = await this.loadOpenPlay(bookingId);
    if (booking.userId !== userId) throw new ForbiddenException(MSG.NOT_BOOKER);
    if (booking.isActive !== true) throw new ConflictException(MSG.INACTIVE);

    const now = new Date();
    if (hasStarted(booking.bookDate, now)) {
      throw new ConflictException(MSG.STARTED);
    }

    const outcome = await this.repository.cancelBooking({
      bookingId,
      bookerId: userId,
      now,
    });
    if (outcome.kind === 'OTHER_PLAYERS') {
      throw new ConflictException(MSG.CANCEL_CUTOFF);
    }
    if (outcome.kind === 'NOT_CANCELLABLE') {
      throw new ConflictException(MSG.NO_LONGER_AVAILABLE);
    }
    if (outcome.kind === 'BUSY') throw new ConflictException(MSG.BUSY);
  }

  /**
   * Marks an existing booking Open Play; venue staff only (AC-01).
   *
   * @param   {string}            bookingId The booking id.
   * @param   {string}            userId    The signed-in user.
   * @param   {EnableOpenPlayDto} dto       Optional capacity / public flag.
   * @returns {Promise<OpenPlayManageResponse>}
   * @throws  {NotFoundException}  Unknown booking.
   * @throws  {ForbiddenException} Caller is not staff of the booking's venue.
   * @throws  {ConflictException}  Already Open Play, cancelled, started, no booker, or lost race.
   */
  async enable(
    bookingId: string,
    userId: string,
    dto: EnableOpenPlayDto,
  ): Promise<OpenPlayManageResponse> {
    const booking = await this.repository.findById(bookingId);
    if (!booking) throw new NotFoundException(MSG.BOOKING_NOT_FOUND);
    if (!(await this.isStaff(booking, userId))) {
      throw new ForbiddenException(MSG.STAFF_ONLY);
    }
    if (booking.isOpenPlay) throw new ConflictException(MSG.ALREADY_OPEN_PLAY);
    if (booking.isActive !== true) throw new ConflictException(MSG.INACTIVE);

    const now = new Date();
    if (hasStarted(booking.bookDate, now)) {
      throw new ConflictException(MSG.STARTED);
    }
    if (booking.userId === null) throw new ConflictException(MSG.NO_BOOKER);

    const outcome = await this.repository.enableOpenPlay({
      bookingId,
      now,
      capacity: dto.capacity ?? DEFAULT_OPEN_PLAY_CAPACITY,
      isPublic: dto.isPublic ?? false,
      token: this.tokenHelper.generate(),
    });
    if (outcome.kind === 'NOT_ENABLEABLE') {
      throw new ConflictException(MSG.NO_LONGER_AVAILABLE);
    }
    if (outcome.kind === 'BUSY') throw new ConflictException(MSG.BUSY);
    return this.buildManageView(await this.loadOpenPlay(bookingId));
  }

  /**
   * Toggles public listing; booker or venue staff (AC-02).
   *
   * @param   {string}                   bookingId The booking id.
   * @param   {string}                   userId    The signed-in user.
   * @param   {SetOpenPlayVisibilityDto} dto       The new flag.
   * @returns {Promise<OpenPlayManageResponse>}
   * @throws  {NotFoundException}  Unknown booking.
   * @throws  {ForbiddenException} Neither booker nor venue staff.
   * @throws  {ConflictException}  Not Open Play, cancelled, or lost race.
   */
  async setVisibility(
    bookingId: string,
    userId: string,
    dto: SetOpenPlayVisibilityDto,
  ): Promise<OpenPlayManageResponse> {
    const booking = await this.repository.findById(bookingId);
    if (!booking) throw new NotFoundException(MSG.BOOKING_NOT_FOUND);
    await this.assertCanManage(booking, userId);
    if (!this.isOpenPlay(booking)) throw new ConflictException(MSG.NOT_OPEN_PLAY);
    if (booking.isActive !== true) throw new ConflictException(MSG.INACTIVE);

    const updated = await this.repository.setVisibility(bookingId, dto.isPublic);
    if (!updated) throw new ConflictException(MSG.NO_LONGER_AVAILABLE);

    return this.buildManageView({ ...booking, isOpenPlayPublic: dto.isPublic });
  }

  /**
   * Management read (token + roster names); booker or venue staff.
   *
   * @param   {string} bookingId The booking id.
   * @param   {string} userId    The signed-in user.
   * @returns {Promise<OpenPlayManageResponse>}
   * @throws  {NotFoundException}  Unknown / not Open Play.
   * @throws  {ForbiddenException} Neither booker nor venue staff.
   */
  async getManageView(
    bookingId: string,
    userId: string,
  ): Promise<OpenPlayManageResponse> {
    const booking = await this.loadOpenPlay(bookingId);
    await this.assertCanManage(booking, userId);
    return this.buildManageView(booking);
  }

  private async join(
    booking: OpenPlayRecord,
    userId: string,
    requirePublic: boolean,
  ): Promise<JoinOpenPlayResponse> {
    // `booking` came from a findViewable* read, so it is already active, at
    // an ACTIVE venue, with a booker. joinSeat re-checks all of it under the lock.
    const now = new Date();
    if (hasStarted(booking.bookDate, now)) {
      throw new ConflictException(MSG.STARTED);
    }

    const outcome = await this.repository.joinSeat({
      bookingId: booking.id,
      userId,
      now,
      requirePublic,
    });
    switch (outcome.kind) {
      case 'JOINED':
        return {
          bookingId: booking.id,
          confirmedSeats: outcome.confirmedSeats,
          capacity: outcome.capacity,
          isFull: isFull(outcome.confirmedSeats, outcome.capacity),
        };
      case 'FULL':
        throw new ConflictException(MSG.FULL);
      case 'ALREADY_SEATED':
        throw new ConflictException(MSG.ALREADY_SEATED);
      case 'NOT_JOINABLE':
        throw new ConflictException(MSG.NO_LONGER_AVAILABLE);
      case 'BUSY':
        throw new ConflictException(MSG.BUSY);
    }
  }

  private async loadOpenPlay(bookingId: string): Promise<OpenPlayRecord> {
    const booking = await this.repository.findById(bookingId);
    if (!this.isOpenPlay(booking)) throw new NotFoundException(MSG.NOT_FOUND);
    return booking;
  }

  private isOpenPlay(
    booking: OpenPlayBookingRecord | null,
  ): booking is OpenPlayRecord {
    return (
      booking !== null &&
      booking.isOpenPlay &&
      booking.openPlayCapacity !== null &&
      booking.openPlayJoinToken !== null
    );
  }

  private isStaff(
    booking: OpenPlayBookingRecord,
    userId: string,
  ): Promise<boolean> {
    return this.repository.hasVenueStaffMembership(
      userId,
      booking.court.venue.tenantId,
      booking.venueId,
    );
  }

  private async assertCanManage(
    booking: OpenPlayBookingRecord,
    userId: string,
  ): Promise<void> {
    if (booking.userId === userId) return;
    if (await this.isStaff(booking, userId)) return;
    throw new ForbiddenException(MSG.FORBIDDEN_MANAGE);
  }

  private async buildManageView(
    booking: OpenPlayRecord,
  ): Promise<OpenPlayManageResponse> {
    const roster = await this.repository.findRoster(booking.id);
    return {
      listing: this.toListing(booking),
      isPublic: booking.isOpenPlayPublic,
      isActive: booking.isActive === true,
      joinToken: booking.openPlayJoinToken,
      roster: roster.map((seat) => ({
        name: seat.user.name,
        isBooker: seat.isBooker,
        joinedAt: seat.createdAt.toISOString(),
      })),
    };
  }

  /** Explicit field-by-field mapping. Never spread a record here (AC-08). */
  private toListing(record: OpenPlayListingRecord): OpenPlayListing {
    const capacity = record.openPlayCapacity ?? 0;
    const confirmedSeats = record.confirmedSeats;
    return {
      id: record.id,
      startsAt: record.bookDate.toISOString(),
      venue: {
        id: record.court.venue.id,
        name: record.court.venue.name,
        slug: record.court.venue.slug,
        city: record.court.venue.city,
        timezone: record.court.venue.timezone,
      },
      court: { id: record.court.id, name: record.court.name },
      capacity,
      confirmedSeats,
      isFull: isFull(confirmedSeats, capacity),
    };
  }
}
```

## Task 8: DB-backed integration spec (concurrency, constraints, exposure)

**Files:**
- Create: `apps/api/src/open-play/open-play.integration.spec.ts`

**Interfaces:**
- Consumes: `OpenPlayRepository` (Task 5), `CourtBookRepository.hasConflictBooking` (Task 4). Requires a migrated database at `TEST_DATABASE_URL`. Without one the suite is skipped (`describe.skip`), the same as `court-book.integration.spec.ts`.

What this spec proves that the mocked specs can't:

- **The lock really serializes joins.** Eight concurrent joins race for one remaining seat. A two-way `Promise.all` rarely interleaves inside the race window and can pass with the lock removed; eight (under the `pg` pool default of 10 connections, so none queue for a connection) makes a broken lock show up as more than one `JOINED`.
- **Join vs. cancel can't produce a cancelled booking holding a non-booker seat**, inside the 24h window, raced over several rounds.
- **The shared viewable/joinable builder excludes the right rows** (cancelled, `PENDING`/`SUSPENDED` venue, booker deleted) on discovery, on the token/id reads, and in the lock.
- **The AC-08 staff check against real `TenantMember` rows**, which every other spec only mocks.
- **The `isVacant` conflict filter**, including a schedule row whose nullable `isActive` is `NULL`.

```ts
import { randomUUID } from 'node:crypto';
import { PrismaPg } from '@prisma/adapter-pg';
import { Prisma, PrismaClient } from '../generated/prisma/client';
import { CourtBookRepository } from '../court-book/court-book.repository';
import type { PrismaService } from '../prisma/prisma.service';
import { OpenPlayRepository } from './open-play.repository';

const TEST_DATABASE_URL = process.env.TEST_DATABASE_URL;
const describeIfDb = TEST_DATABASE_URL ? describe : describe.skip;
const HOUR = 60 * 60 * 1000;
const DAY = 24 * HOUR;
const FORBIDDEN = ['userEmail', 'userId', 'referenceId', 'isPaid', 'totalPrice', 'openPlayJoinToken', 'tenantId'];

type VenueStatus = 'ACTIVE' | 'PENDING' | 'SUSPENDED';

describeIfDb('open play (requires TEST_DATABASE_URL)', () => {
  let db: PrismaClient;
  let repo: OpenPlayRepository;
  let courtBookRepo: CourtBookRepository;
  const run = randomUUID().slice(0, 8);
  const ids = { users: [] as string[], tenants: [] as string[], venues: [] as string[], courts: [] as string[], bookings: [] as string[] };

  beforeAll(() => {
    db = new PrismaClient({ adapter: new PrismaPg(TEST_DATABASE_URL as string) });
    const prisma = { db } as unknown as PrismaService;
    repo = new OpenPlayRepository(prisma);
    courtBookRepo = new CourtBookRepository(prisma);
  });

  afterAll(async () => {
    await db.openPlaySeat.deleteMany({ where: { bookingId: { in: ids.bookings } } });
    await db.courtBooking.deleteMany({ where: { id: { in: ids.bookings } } });
    await db.courtSchedule.deleteMany({ where: { courtId: { in: ids.courts } } });
    await db.court.deleteMany({ where: { id: { in: ids.courts } } });
    await db.tenantMember.deleteMany({ where: { tenantId: { in: ids.tenants } } });
    await db.venue.deleteMany({ where: { id: { in: ids.venues } } });
    await db.tenant.deleteMany({ where: { id: { in: ids.tenants } } });
    await db.user.deleteMany({ where: { id: { in: ids.users } } });
    await db.$disconnect();
  });

  async function user(label: string): Promise<string> {
    const u = await db.user.create({ data: { name: `U ${label}`, email: `${label}-${run}@example.com` } });
    ids.users.push(u.id);
    return u.id;
  }

  async function tenant(): Promise<string> {
    const t = await db.tenant.create({ data: { name: `T ${run}` } });
    ids.tenants.push(t.id);
    return t.id;
  }

  async function venue(tenantId: string, status: VenueStatus = 'ACTIVE'): Promise<string> {
    const v = await db.venue.create({
      data: { tenantId, name: 'V', slug: `op-${randomUUID().slice(0, 8)}`, status },
    });
    ids.venues.push(v.id);
    return v.id;
  }

  async function court(status: VenueStatus = 'ACTIVE'): Promise<{ tenantId: string; venueId: string; courtId: string }> {
    const tenantId = await tenant();
    const venueId = await venue(tenantId, status);
    const c = await db.court.create({ data: { venueId, name: 'C' } });
    ids.courts.push(c.id);
    return { tenantId, venueId, courtId: c.id };
  }

  async function openPlay(args: {
    bookerId: string; capacity: number; isPublic?: boolean; startsInMs?: number;
    isActive?: boolean; status?: VenueStatus;
  }): Promise<{ id: string; courtId: string; venueId: string; referenceId: string; bookDate: Date; joinToken: string }> {
    const { venueId, courtId } = await court(args.status);
    const bookDate = new Date(Date.now() + (args.startsInMs ?? 7 * DAY));
    const referenceId = `RH-${randomUUID().slice(0, 8)}`;
    const joinToken = randomUUID();
    const b = await db.courtBooking.create({
      data: {
        venueId, courtId, userEmail: 'b@example.com', userId: args.bookerId, bookDate,
        isActive: args.isActive ?? true, referenceId, isOpenPlay: true,
        openPlayCapacity: args.capacity, isOpenPlayPublic: args.isPublic ?? true,
        openPlayJoinToken: joinToken,
        openPlaySeats: { create: { userId: args.bookerId, isBooker: true } },
      },
    });
    ids.bookings.push(b.id);
    await db.courtSchedule.create({
      data: {
        courtId, venueId, userEmail: 'b@example.com', userId: args.bookerId, bookedDate: bookDate,
        isVacant: false, isActive: true, hoursBooked: 2,
        dateTimeVacant: new Date(bookDate.getTime() + 2 * HOUR), referenceId,
      },
    });
    return { id: b.id, courtId, venueId, referenceId, bookDate, joinToken };
  }

  it('lets exactly one of eight concurrent joins take the last seat', async () => {
    const booker = await user('booker1');
    // 8 racers: enough to interleave inside the lock window, and under the
    // pg pool default of 10 so no racer is serialized by connection checkout.
    const racers = await Promise.all(Array.from({ length: 8 }, (_, i) => user(`racer1-${i}`)));
    const booking = await openPlay({ bookerId: booker, capacity: 2 });
    const now = new Date();

    const outcomes = await Promise.all(
      racers.map((userId) => repo.joinSeat({ bookingId: booking.id, userId, now, requirePublic: false })),
    );

    const kinds = outcomes.map((o) => o.kind);
    expect(kinds.filter((k) => k === 'JOINED')).toHaveLength(1);
    expect(kinds.filter((k) => k === 'FULL')).toHaveLength(7);
    expect(await db.openPlaySeat.count({ where: { bookingId: booking.id } })).toBe(2);
  });

  it('lets one of two concurrent joins by the same user win, and the unique constraint backs it', async () => {
    const booker = await user('booker2');
    const a = await user('a2');
    const booking = await openPlay({ bookerId: booker, capacity: 4 });
    const now = new Date();

    const outcomes = await Promise.all([
      repo.joinSeat({ bookingId: booking.id, userId: a, now, requirePublic: false }),
      repo.joinSeat({ bookingId: booking.id, userId: a, now, requirePublic: false }),
    ]);
    expect(outcomes.map((o) => o.kind).sort()).toEqual(['ALREADY_SEATED', 'JOINED']);

    await expect(
      db.openPlaySeat.create({ data: { bookingId: booking.id, userId: a } }),
    ).rejects.toMatchObject({ code: 'P2002' } satisfies Partial<Prisma.PrismaClientKnownRequestError>);
  });

  it('never leaves a cancelled booking holding a non-booker seat when join races cancel inside 24h', async () => {
    for (let round = 0; round < 5; round++) {
      const booker = await user(`booker-jc-${round}`);
      const joiner = await user(`joiner-jc-${round}`);
      const booking = await openPlay({ bookerId: booker, capacity: 4, startsInMs: 12 * HOUR });
      const now = new Date();

      const [join, cancel] = await Promise.all([
        repo.joinSeat({ bookingId: booking.id, userId: joiner, now, requirePublic: false }),
        repo.cancelBooking({ bookingId: booking.id, bookerId: booker, now }),
      ]);

      const { isActive } = await db.courtBooking.findUniqueOrThrow({
        where: { id: booking.id },
        select: { isActive: true },
      });
      const others = await db.openPlaySeat.count({ where: { bookingId: booking.id, isBooker: false } });
      const order = `${join.kind}/${cancel.kind}`;

      // Exactly one of the two serial orders, never a mix.
      expect(['JOINED/OTHER_PLAYERS', 'NOT_JOINABLE/CANCELLED']).toContain(order);
      expect({ isActive, others }).toEqual(
        order === 'JOINED/OTHER_PLAYERS' ? { isActive: true, others: 1 } : { isActive: false, others: 0 },
      );
    }
  });

  it('rejects a join on an already-cancelled booking', async () => {
    const booker = await user('booker-cx');
    const a = await user('a-cx');
    const booking = await openPlay({ bookerId: booker, capacity: 4, isActive: false });

    expect((await repo.joinSeat({ bookingId: booking.id, userId: a, now: new Date(), requirePublic: false })).kind)
      .toBe('NOT_JOINABLE');
    expect(await repo.findViewableByToken(booking.joinToken)).toBeNull();
    expect(await db.openPlaySeat.count({ where: { bookingId: booking.id } })).toBe(1);
  });

  it('reopens a full booking when a player leaves', async () => {
    const booker = await user('booker3');
    const a = await user('a3');
    const c = await user('c3');
    const booking = await openPlay({ bookerId: booker, capacity: 2 });
    const now = new Date();

    expect((await repo.joinSeat({ bookingId: booking.id, userId: a, now, requirePublic: false })).kind).toBe('JOINED');
    expect((await repo.joinSeat({ bookingId: booking.id, userId: c, now, requirePublic: false })).kind).toBe('FULL');
    expect((await repo.leaveSeat({ bookingId: booking.id, userId: a, now })).kind).toBe('LEFT');
    expect((await repo.joinSeat({ bookingId: booking.id, userId: c, now, requirePublic: false })).kind).toBe('JOINED');
  });

  it('discovery keeps full games, excludes private/cancelled/past/non-ACTIVE-venue/booker-deleted ones, and leaks no forbidden fields', async () => {
    const booker = await user('booker4');
    const full = await openPlay({ bookerId: booker, capacity: 1 });
    const hidden = await openPlay({ bookerId: booker, capacity: 4, isPublic: false });
    const cancelled = await openPlay({ bookerId: booker, capacity: 4, isActive: false });
    const past = await openPlay({ bookerId: booker, capacity: 4, startsInMs: -DAY });
    const pendingVenue = await openPlay({ bookerId: booker, capacity: 4, status: 'PENDING' });
    const suspendedVenue = await openPlay({ bookerId: booker, capacity: 4, status: 'SUSPENDED' });
    const ghost = await user('ghost4');
    const orphaned = await openPlay({ bookerId: ghost, capacity: 4 });
    await db.user.delete({ where: { id: ghost } }); // booking.userId -> NULL, booker seat cascades away

    // Each fixture booking has its own venue, so query per venue: other rows
    // in a shared test DB can never push ours off the page.
    const listFor = async (b: { venueId: string }) =>
      (await repo.listPublic({ now: new Date(), venueId: b.venueId, skip: 0, take: 50 })).records;
    const records = (
      await Promise.all([full, hidden, cancelled, past, pendingVenue, suspendedVenue, orphaned].map(listFor))
    ).flat();
    const listed = records.map((r) => r.id);

    expect(listed).toContain(full.id);
    expect(records.find((r) => r.id === full.id)?.confirmedSeats).toBe(1);
    for (const excluded of [hidden, cancelled, past, pendingVenue, suspendedVenue, orphaned]) {
      expect(listed).not.toContain(excluded.id);
    }
    const keys = JSON.stringify(records);
    for (const forbidden of FORBIDDEN) expect(keys).not.toContain(`"${forbidden}"`);
  });

  it('hides SUSPENDED-venue and booker-deleted games from the token/id reads and refuses joins under the lock', async () => {
    const booker = await user('booker6');
    const joiner = await user('joiner6');
    const suspended = await openPlay({ bookerId: booker, capacity: 4, status: 'SUSPENDED' });
    const ghost = await user('ghost6');
    const orphaned = await openPlay({ bookerId: ghost, capacity: 4 });
    await db.user.delete({ where: { id: ghost } });

    for (const b of [suspended, orphaned]) {
      expect(await repo.findViewableByToken(b.joinToken)).toBeNull();
      expect(await repo.findViewableById(b.id)).toBeNull();
      expect((await repo.joinSeat({ bookingId: b.id, userId: joiner, now: new Date(), requirePublic: false })).kind)
        .toBe('NOT_JOINABLE');
    }
    // The management read still sees the suspended-venue booking.
    expect(await repo.findById(suspended.id)).not.toBeNull();
  });

  it('cancel deactivates the booking, frees its schedule rows, and frees the court slot', async () => {
    const booker = await user('booker5');
    const booking = await openPlay({ bookerId: booker, capacity: 4 });
    const start = booking.bookDate.toISOString();
    const end = new Date(booking.bookDate.getTime() + HOUR);

    expect(await courtBookRepo.hasConflictBooking(booking.courtId, end, start)).toBe(true);
    expect((await repo.cancelBooking({ bookingId: booking.id, bookerId: booker, now: new Date() })).kind).toBe('CANCELLED');

    const row = await db.courtBooking.findUniqueOrThrow({ where: { id: booking.id }, select: { isActive: true } });
    expect(row.isActive).toBe(false);
    const schedules = await db.courtSchedule.findMany({
      where: { referenceId: booking.referenceId, courtId: booking.courtId },
      select: { isActive: true, isVacant: true },
    });
    expect(schedules).toEqual([{ isActive: false, isVacant: true }]);
    expect(await courtBookRepo.hasConflictBooking(booking.courtId, end, start)).toBe(false);
  });
```

```ts
import { isAxiosError } from "axios"

/** Pulls the NestJS `message` out of an Axios error, falling back to a generic line. */
function getApiErrorMessage(
  error: unknown,
  fallback = "Something went wrong. Please try again."
): string {
  if (isAxiosError<{ message?: string | string[] }>(error)) {
    const message = error.response?.data?.message
    if (Array.isArray(message)) return message.join(" ")
    if (typeof message === "string" && message.length > 0) return message
  }
  return fallback
}

export { getApiErrorMessage }
```

```ts
/**
 * Converts a `YYYY-MM-DD` picked in the browser to that local day's [from, to)
 * ISO instants. The discovery list spans venues, so there's no single venue
 * zone to filter in; the filter uses the viewer's day (see the spec).
 */
function localDayRange(date: string): { from: string; to: string } {
  const start = new Date(`${date}T00:00:00`)
  const end = new Date(start)
  end.setDate(end.getDate() + 1)
  return { from: start.toISOString(), to: end.toISOString() }
}

const formatters = new Map<string, Intl.DateTimeFormat>()

function startsAtFormatter(timeZone: string): Intl.DateTimeFormat {
  let formatter = formatters.get(timeZone)
  if (!formatter) {
    formatter = new Intl.DateTimeFormat(undefined, {
      weekday: "short",
      month: "short",
      day: "numeric",
      hour: "numeric",
      minute: "2-digit",
      timeZone,
      timeZoneName: "short",
    })
    formatters.set(timeZone, formatter)
  }
  return formatter
}

/**
 * Formats a game's start in the **venue's** timezone (with the zone
 * abbreviation), so it reads the same for every viewer. Falls back to the
 * browser zone only if the venue's zone string is invalid.
 */
function formatStartsAt(iso: string, timeZone: string): string {
  try {
    return startsAtFormatter(timeZone).format(new Date(iso))
  } catch {
    return new Date(iso).toLocaleString()
  }
}

export { formatStartsAt, localDayRange }
```
