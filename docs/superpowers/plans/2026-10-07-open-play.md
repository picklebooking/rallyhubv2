# Open Play Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `CourtBooking.isOpenPlay` real. Open Play bookings get a capacity (default 4, booker included), a roster of immediately-confirmed seats, a non-guessable join link, an optional public listing on an anonymous cross-venue discovery endpoint, and leave/cancel rules with a 24-hour cutoff. The web gets a `/open-play` discovery page and a join-link page.

**Architecture:** One additive Prisma migration: three Open Play columns on `CourtBooking` and a new `OpenPlaySeat` table with `@@unique([bookingId, userId])`. `CourtBookModule` handles create-time opt-in. A new sibling `OpenPlayModule` (thin controller, service, repository) handles discovery, join, leave, cancel, enable-on-existing, visibility, and a management read. Every seat-changing operation runs inside a Prisma interactive `$transaction` that starts by row-locking the booking with a conditional `updateMany`. Authorization reads the venue/tenant from the booking itself and checks `TenantMember` for staff. It never trusts request context.

**Tech Stack:** NestJS 11, Prisma 7 (`prisma-client` generator, `PrismaPg` adapter), class-validator / class-transformer DTOs, Jest (`ts-jest`, `@jest/globals`), Better Auth via `@thallesp/nestjs-better-auth` (`@Session`, `@AllowAnonymous`, `@OptionalAuth`), `@workspace/shared` type-only contracts, Next.js 16 App Router, TanStack Query v5, React Hook Form + Zod v4, `@workspace/ui` shadcn primitives.

**Spec:** `docs/superpowers/specs/2026-10-07-open-play-design.md`

## Global Constraints

- **Never run `npx prisma migrate dev`, `prisma migrate deploy`, `prisma db push`, or `npm install`.** Task 1 edits `schema.prisma`, validates it, and STOPS for a human to run the migration.
- **Commit messages must contain no AI attribution.** No `Co-Authored-By: Claude…`, no 🤖 line, no "Generated with" line. This repo forbids them regardless of any harness default.
- Default capacity is `4`, and capacity includes the booker's seat. Capacity must be a positive whole number (`@IsInt() @Min(1)`). There is no upper bound.
- The leave/cancel cutoff is exactly 24 hours (`24 * 60 * 60 * 1000` ms) before `bookDate`. "Until 24 hours before" means allowed while `now <= bookDate − 24h`.
- Discovery and by-token responses must never contain `userEmail`, `userId`, `referenceId`, `isPaid`, `totalPrice`, `openPlayJoinToken`/`joinToken`, or `tenantId`.
- AC-05 (cost sharing) is deferred. Don't touch `totalPrice`/`isPaid` semantics, and add no per-seat pricing or payment fields.
- Read the booking's venue and tenant from the booking (`booking.venueId`, `booking.court.venue.tenantId`). Never use `@CurrentVenue()`/`@CurrentTenant()` in `OpenPlayController`.
- Match repo conventions: thin controller → service → repository; JSDoc on every public method (`@param`/`@returns`/`@throws`); class-validator DTOs; no `any`; explicit return types; type-only `@workspace/shared` imports.
- Frontend: thin route files, `@workspace/ui` primitives only (no `shadcn add`), shared theme tokens (no ad hoc tints like `bg-muted/30`), both light and dark mode, and explicit `isPending`/error/empty states for every query.
- TDD for all API work: failing test → watch it fail → minimal implementation → watch it pass → commit.

```ts
/** Seats (including the booker's) when the creator gives no capacity. */
export const DEFAULT_OPEN_PLAY_CAPACITY = 4;

/** Discovery pagination defaults. */
export const DEFAULT_OPEN_PLAY_PAGE_SIZE = 20;
export const MAX_OPEN_PLAY_PAGE_SIZE = 50;

/** Leaving / cancelling closes this long before the start time. */
export const OPEN_PLAY_CUTOFF_MS = 24 * 60 * 60 * 1000;

/**
 * Whether the booking's start time has been reached.
 *
 * @param   {Date}    bookDate The booking's start time.
 * @param   {Date}    now      The current time.
 * @returns {boolean}          `true` once `now >= bookDate`.
 */
export function hasStarted(bookDate: Date, now: Date): boolean {
  return now.getTime() >= bookDate.getTime();
}

/**
 * Whether `now` is inside the 24-hour window before start. Exactly 24h
 * before start is still outside the window ("until 24 hours before").
 *
 * @param   {Date}    bookDate The booking's start time.
 * @param   {Date}    now      The current time.
 * @returns {boolean}          `true` when `now > bookDate - 24h`.
 */
export function isInsideCutoff(bookDate: Date, now: Date): boolean {
  return now.getTime() > bookDate.getTime() - OPEN_PLAY_CUTOFF_MS;
}

/**
 * The earliest start time that is still outside the cutoff at `now`, for
 * use as a `bookDate >= …` database filter.
 *
 * @param   {Date} now The current time.
 * @returns {Date}     `now + 24h`.
 */
export function latestLeaveableStart(now: Date): Date {
  return new Date(now.getTime() + OPEN_PLAY_CUTOFF_MS);
}

/**
 * Whether confirmed seats have reached capacity.
 *
 * @param   {number}  confirmedSeats Seats currently held (booker included).
 * @param   {number}  capacity       Total seats.
 * @returns {boolean}                `true` when no seat is left.
 */
export function isFull(confirmedSeats: number, capacity: number): boolean {
  return confirmedSeats >= capacity;
}
```

```ts
import { randomBytes } from 'node:crypto';
import { Injectable } from '@nestjs/common';

/** 24 random bytes -> 32 base64url chars (192 bits). */
const TOKEN_BYTES = 24;

@Injectable()
export class OpenPlayTokenHelper {
  /**
   * Generates a non-guessable Open Play join token.
   *
   * Unlike `PNRHelper`, there is no regenerate-until-unique loop: at 192
   * bits a collision is not a practical concern, and
   * `CourtBooking.openPlayJoinToken @unique` is the DB backstop.
   *
   * @returns {string} A 32-character base64url token.
   */
  public generate(): string {
    return randomBytes(TOKEN_BYTES).toString('base64url');
  }
}
```

```ts
  now: Date;

  from?: Date;
  to?: Date;
  skip: number;
  take: number;
};

export type JoinSeatOutcome =
  | { kind: 'JOINED'; confirmedSeats: number; capacity: number }
  | { kind: 'FULL' }
  | { kind: 'ALREADY_SEATED' }
  | { kind: 'NOT_JOINABLE' };
export type LeaveSeatOutcome =
  | { kind: 'LEFT' }
  | { kind: 'NO_SEAT' }
  | { kind: 'NOT_LEAVABLE' };
export type CancelOutcome =
  | { kind: 'CANCELLED' }
  | { kind: 'OTHER_PLAYERS' }
  | { kind: 'NOT_CANCELLABLE' };
export type EnableOutcome = { kind: 'ENABLED' } | { kind: 'NOT_ENABLEABLE' };

export type OpenPlayRosterRecord = {
  isBooker: boolean;
  createdAt: Date;
  user: { name: string };
};

@Injectable()
export class OpenPlayRepository {
  /**
   * Constructs the `OpenPlayRepository`.
   *
   * @param {PrismaService} prisma The Prisma service.
   */
  constructor(private readonly prisma: PrismaService) {}

  /**
   * Lists publicly visible, active, upcoming Open Play bookings at ACTIVE
   * venues, oldest start first.
   *
   * @param   {OpenPlayListFilter} filter Time, optional venue/range, page window.
   * @returns {Promise<{ records: OpenPlayListingRecord[]; total: number }>}
   */
  async listPublic(
    filter: OpenPlayListFilter,
  ): Promise<{ records: OpenPlayListingRecord[]; total: number }> {
    const bookDate: Prisma.DateTimeFilter<'CourtBooking'> = { gt: filter.now };
    if (filter.from) bookDate.gte = filter.from;
    if (filter.to) bookDate.lt = filter.to;

    const where: Prisma.CourtBookingWhereInput = {
      isOpenPlay: true,
      isOpenPlayPublic: true,
      isActive: true,
      openPlayCapacity: { not: null },
      bookDate,
      court: { venue: { status: 'ACTIVE' } },
      ...(filter.venueId ? { venueId: filter.venueId } : {}),
    };

    const [records, total] = await this.prisma.db.$transaction([
      this.prisma.db.courtBooking.findMany({
        where,
        select: LISTING_SELECT,
        orderBy: [{ bookDate: 'asc' }, { id: 'asc' }],
        skip: filter.skip,
        take: filter.take,
      }),
      this.prisma.db.courtBooking.count({ where }),
    ]);

    return { records, total };
  }

  /**
   * Finds a booking (any kind) by id, with the fields Open Play rules need.
   *
   * @param   {string} id The booking id.
   * @returns {Promise<OpenPlayBookingRecord | null>}
   */
  async findById(id: string): Promise<OpenPlayBookingRecord | null> {
    return this.prisma.db.courtBooking.findUnique({
      where: { id },
      select: BOOKING_SELECT,
    });
  }

  /**
   * Finds a booking by its Open Play join token.
   *
   * @param   {string} token The join token.
   * @returns {Promise<OpenPlayBookingRecord | null>}
   */
  async findByToken(token: string): Promise<OpenPlayBookingRecord | null> {
    return this.prisma.db.courtBooking.findUnique({
      where: { openPlayJoinToken: token },
      select: BOOKING_SELECT,
    });
  }

  /**
   * Finds a user's seat on a booking.
   *
   * @param   {string} bookingId The booking id.
   * @param   {string} userId    The user id.
   * @returns {Promise<{ isBooker: boolean } | null>}
   */
  async findSeat(
    bookingId: string,
    userId: string,
  ): Promise<{ isBooker: boolean } | null> {
    return this.prisma.db.openPlaySeat.findUnique({
      where: { bookingId_userId: { bookingId, userId } },
      select: { isBooker: true },
    });
  }

  /**
   * Lists a booking's roster, booker first, then by join time.
   *
   * @param   {string} bookingId The booking id.
   * @returns {Promise<OpenPlayRosterRecord[]>}
   */
  async findRoster(bookingId: string): Promise<OpenPlayRosterRecord[]> {
    return this.prisma.db.openPlaySeat.findMany({
      where: { bookingId },
      select: { isBooker: true, createdAt: true, user: { select: { name: true } } },
      orderBy: [{ isBooker: 'desc' }, { createdAt: 'asc' }],
    });
  }

  /**
   * Whether the user is OWNER/STAFF of the tenant, either tenant-wide
   * (`venueId = null`) or scoped to this venue.
   *
   * @param   {string} userId   The user id.
   * @param   {string} tenantId The booking's tenant id.
   * @param   {string} venueId  The booking's venue id.
   * @returns {Promise<boolean>}
   */
  async hasVenueStaffMembership(
    userId: string,
    tenantId: string,
    venueId: string,
  ): Promise<boolean> {
    const member = await this.prisma.db.tenantMember.findFirst({
      where: {
        userId,
        tenantId,
        role: { in: ['OWNER', 'STAFF'] },
        OR: [{ venueId: null }, { venueId }],
      },
      select: { id: true },
    });
    return member !== null;
  }

  /**
   * Reserves a seat. Concurrency-safe: the conditional `updateMany` takes a
   * row lock on the booking (held until commit), so concurrent joins on one
   * booking serialize, and under READ COMMITTED each later statement sees
   * seats committed by the previous lock holder. The capacity check lives
   * here, not in the service, because it must run under that lock.
   *
   * @param   {{ bookingId: string; userId: string; now: Date; requirePublic: boolean }} args
   * @returns {Promise<JoinSeatOutcome>}
   */
  async joinSeat(args: {
    bookingId: string;
    userId: string;
    now: Date;
    requirePublic: boolean;
  }): Promise<JoinSeatOutcome> {
    const { bookingId, userId, now, requirePublic } = args;

    return this.prisma.db.$transaction(async (tx) => {
      const locked = await tx.courtBooking.updateMany({
        where: {
          id: bookingId,
          isOpenPlay: true,
          isActive: true,
          openPlayCapacity: { not: null },
          bookDate: { gt: now },
          ...(requirePublic ? { isOpenPlayPublic: true } : {}),
        },
        data: { updatedAt: now },
      });
      if (locked.count === 0) return { kind: 'NOT_JOINABLE' } as const;

      const existing = await tx.openPlaySeat.findUnique({
        where: { bookingId_userId: { bookingId, userId } },
        select: { id: true },
      });
      if (existing) return { kind: 'ALREADY_SEATED' } as const;

      const booking = await tx.courtBooking.findUniqueOrThrow({
        where: { id: bookingId },
        select: {
          openPlayCapacity: true,
          _count: { select: { openPlaySeats: true } },
        },
      });
      const capacity = booking.openPlayCapacity ?? 0;
      const confirmed = booking._count.openPlaySeats;
      if (isFull(confirmed, capacity)) return { kind: 'FULL' } as const;

      await tx.openPlaySeat.create({
        data: { bookingId, userId, isBooker: false },
      });
      return { kind: 'JOINED', confirmedSeats: confirmed + 1, capacity } as const;
    });
  }

  /**
   * Releases a non-booker seat, only while the booking starts at or after
   * `now + 24h`. Locks the booking like `joinSeat`.
   *
   * @param   {{ bookingId: string; userId: string; now: Date }} args
   * @returns {Promise<LeaveSeatOutcome>}
   */
  async leaveSeat(args: {
    bookingId: string;
    userId: string;
    now: Date;
  }): Promise<LeaveSeatOutcome> {
    const { bookingId, userId, now } = args;

    return this.prisma.db.$transaction(async (tx) => {
      const locked = await tx.courtBooking.updateMany({
        where: {
          id: bookingId,
          isOpenPlay: true,
          isActive: true,
          bookDate: { gte: latestLeaveableStart(now) },
        },
        data: { updatedAt: now },
      });
      if (locked.count === 0) return { kind: 'NOT_LEAVABLE' } as const;

      const deleted = await tx.openPlaySeat.deleteMany({
        where: { bookingId, userId, isBooker: false },
      });
      return deleted.count > 0
        ? ({ kind: 'LEFT' } as const)
        : ({ kind: 'NO_SEAT' } as const);
    });
  }

  /**
   * Soft-cancels an Open Play booking and frees its schedule rows. Inside
   * the 24h window this is refused while any non-booker seat exists. Locks
   * the booking like `joinSeat`, so it cannot race a join.
   *
   * @param   {{ bookingId: string; bookerId: string; now: Date }} args
   * @returns {Promise<CancelOutcome>}
   */
  async cancelBooking(args: {
    bookingId: string;
    bookerId: string;
    now: Date;
  }): Promise<CancelOutcome> {
    const { bookingId, bookerId, now } = args;

    return this.prisma.db.$transaction(async (tx) => {
      const locked = await tx.courtBooking.updateMany({
        where: {
          id: bookingId,
          isOpenPlay: true,
          isActive: true,
          userId: bookerId,
          bookDate: { gt: now },
        },
        data: { updatedAt: now },
      });
      if (locked.count === 0) return { kind: 'NOT_CANCELLABLE' } as const;

      const booking = await tx.courtBooking.findUniqueOrThrow({
        where: { id: bookingId },
        select: { bookDate: true, courtId: true, referenceId: true },
      });

      if (isInsideCutoff(booking.bookDate, now)) {
        const others = await tx.openPlaySeat.count({
          where: { bookingId, isBooker: false },
        });
        if (others > 0) return { kind: 'OTHER_PLAYERS' } as const;
      }

      await tx.courtBooking.update({
        where: { id: bookingId },
        data: { isActive: false },
      });
      await tx.courtSchedule.updateMany({
        where: { referenceId: booking.referenceId, courtId: booking.courtId },
        data: { isActive: false, isVacant: true },
      });
      return { kind: 'CANCELLED' } as const;
    });
  }

  /**
   * Turns an existing private booking into Open Play and seats its booker.
   *
   * @param   {{ bookingId: string; now: Date; capacity: number; isPublic: boolean; token: string }} args
   * @returns {Promise<EnableOutcome>}
   */
  async enableOpenPlay(args: {
    bookingId: string;
    now: Date;
    capacity: number;
    isPublic: boolean;
    token: string;
  }): Promise<EnableOutcome> {
    const { bookingId, now, capacity, isPublic, token } = args;

    return this.prisma.db.$transaction(async (tx) => {
      const locked = await tx.courtBooking.updateMany({
        where: {
          id: bookingId,
          isOpenPlay: false,
          isActive: true,
          userId: { not: null },
          bookDate: { gt: now },
        },
        data: { updatedAt: now },
      });
      if (locked.count === 0) return { kind: 'NOT_ENABLEABLE' } as const;

      const { userId } = await tx.courtBooking.findUniqueOrThrow({
        where: { id: bookingId },
        select: { userId: true },
      });
      if (userId === null) return { kind: 'NOT_ENABLEABLE' } as const;

      await tx.courtBooking.update({
        where: { id: bookingId },
        data: {
          isOpenPlay: true,
          openPlayCapacity: capacity,
          isOpenPlayPublic: isPublic,
          openPlayJoinToken: token,
        },
      });
      await tx.openPlaySeat.create({
        data: { bookingId, userId, isBooker: true },
      });
      return { kind: 'ENABLED' } as const;
    });
  }

  /**
   * Sets the public-listing flag on an active Open Play booking.
   *
   * @param   {string}  bookingId The booking id.
   * @param   {boolean} isPublic  The new flag.
   * @returns {Promise<boolean>}  `false` if the booking no longer qualifies.
   */
  async setVisibility(bookingId: string, isPublic: boolean): Promise<boolean> {
    const result = await this.prisma.db.courtBooking.updateMany({
      where: { id: bookingId, isOpenPlay: true, isActive: true },
      data: { isOpenPlayPublic: isPublic },
    });
    return result.count > 0;
  }
}
```

```ts
import {
  ConflictException,
  ForbiddenException,
  Injectable,
  NotFoundException,
} from '@nestjs/common';
import type {
  JoinOpenPlayResponse,
  ListOpenPlayResponse,
  OpenPlayByTokenResponse,
  OpenPlayListing,
  OpenPlayManageResponse,
} from '@workspace/shared';
import { ErrorConstant } from '../constants/error-code.constant';
import { OpenPlayTokenHelper } from '../helper/open-play-token.helper';
import type {
  EnableOpenPlayDto,
  ListOpenPlayQueryDto,
  SetOpenPlayVisibilityDto,
} from './dto';
import {
  OpenPlayRepository,
  type OpenPlayBookingRecord,
  type OpenPlayListingRecord,
} from './open-play.repository';
import {
  DEFAULT_OPEN_PLAY_CAPACITY,
  DEFAULT_OPEN_PLAY_PAGE_SIZE,
  hasStarted,
  isFull,
  isInsideCutoff,
} from './open-play.rules';

const MSG = ErrorConstant.OPEN_PLAY_MESSAGES;

/** A booking whose Open Play invariant holds (flag, capacity, token all set). */
type OpenPlayRecord = OpenPlayBookingRecord & {
  isOpenPlay: true;
  openPlayCapacity: number;
  openPlayJoinToken: string;
};

@Injectable()
export class OpenPlayService {
  /**
   * Constructs the `OpenPlayService`.
   *
   * @param {OpenPlayRepository}  repository  Open Play data access.
   * @param {OpenPlayTokenHelper} tokenHelper Join-token generator.
   */
  constructor(
    private readonly repository: OpenPlayRepository,
    private readonly tokenHelper: OpenPlayTokenHelper,
  ) {}

  /**
   * Lists publicly visible Open Play games (AC-07).
   *
   * @param   {ListOpenPlayQueryDto}          query Filters and page.
   * @returns {Promise<ListOpenPlayResponse>}
   */
  async list(query: ListOpenPlayQueryDto): Promise<ListOpenPlayResponse> {
    const page = query.page ?? 1;
    const pageSize = query.pageSize ?? DEFAULT_OPEN_PLAY_PAGE_SIZE;
    const { records, total } = await this.repository.listPublic({
      now: new Date(),
      venueId: query.venueId,
      from: query.from ? new Date(query.from) : undefined,
      to: query.to ? new Date(query.to) : undefined,
      skip: (page - 1) * pageSize,
      take: pageSize,
    });
    return {
      items: records.map((record) => this.toListing(record)),
      page,
      pageSize,
      total,
    };
  }

  /**
   * Views a game via its join link, regardless of public visibility.
   *
   * @param   {string}      token        The join token.
   * @param   {string|null} viewerUserId Signed-in user id, or `null`.
   * @returns {Promise<OpenPlayByTokenResponse>}
   * @throws  {NotFoundException} Unknown token, or not an active Open Play game.
   */
  async getByToken(
    token: string,
    viewerUserId: string | null,
  ): Promise<OpenPlayByTokenResponse> {
    const booking = await this.repository.findByToken(token);
    if (!this.isOpenPlay(booking) || booking.isActive !== true) {
      throw new NotFoundException(MSG.NOT_FOUND);
    }
    const seat = viewerUserId
      ? await this.repository.findSeat(booking.id, viewerUserId)
      : null;
    return {
      listing: this.toListing(booking),
      isPublic: booking.isOpenPlayPublic,
      viewer: viewerUserId
        ? { hasSeat: seat !== null, isBooker: seat?.isBooker ?? false }
        : null,
    };
  }

  /**
   * Joins via the join link (AC-04), regardless of visibility.
   *
   * @param   {string} token  The join token.
   * @param   {string} userId The signed-in user.
   * @returns {Promise<JoinOpenPlayResponse>}
   * @throws  {NotFoundException} Unknown token / not Open Play.
   * @throws  {ConflictException} Cancelled, started, full, already seated, or lost race.
   */
  async joinByToken(token: string, userId: string): Promise<JoinOpenPlayResponse> {
    const booking = await this.repository.findByToken(token);
    if (!this.isOpenPlay(booking)) throw new NotFoundException(MSG.NOT_FOUND);
    return this.join(booking, userId, false);
  }

  /**
   * Joins from the public listing (AC-04). Non-listed games 404.
   *
   * @param   {string} bookingId The booking id.
   * @param   {string} userId    The signed-in user.
   * @returns {Promise<JoinOpenPlayResponse>}
   * @throws  {NotFoundException} Unknown, not Open Play, or not public.
   * @throws  {ConflictException} Cancelled, started, full, already seated, or lost race.
   */
  async joinPublic(bookingId: string, userId: string): Promise<JoinOpenPlayResponse> {
    const booking = await this.repository.findById(bookingId);
    if (!this.isOpenPlay(booking) || !booking.isOpenPlayPublic) {
      throw new NotFoundException(MSG.NOT_FOUND);
    }
    return this.join(booking, userId, true);
  }

  /**
   * Releases the caller's (non-booker) seat, until 24h before start (AC-06).
   *
   * @param   {string} bookingId The booking id.
   * @param   {string} userId    The signed-in user.
   * @returns {Promise<void>}
   * @throws  {NotFoundException} Unknown / not Open Play / no seat.
   * @throws  {ConflictException} Cancelled, booker, inside cutoff, or lost race.
   */
  async leave(bookingId: string, userId: string): Promise<void> {
    const booking = await this.loadOpenPlay(bookingId);
    if (booking.isActive !== true) throw new ConflictException(MSG.INACTIVE);

    const seat = await this.repository.findSeat(bookingId, userId);
    if (!seat) throw new NotFoundException(MSG.NO_SEAT);
    if (seat.isBooker) throw new ConflictException(MSG.BOOKER_CANNOT_LEAVE);

    const now = new Date();
    if (isInsideCutoff(booking.bookDate, now)) {
      throw new ConflictException(MSG.LEAVE_CUTOFF);
    }

    const outcome = await this.repository.leaveSeat({ bookingId, userId, now });
    if (outcome.kind === 'NO_SEAT') throw new NotFoundException(MSG.NO_SEAT);
    if (outcome.kind === 'NOT_LEAVABLE') {
      throw new ConflictException(MSG.NO_LONGER_AVAILABLE);
    }
  }

  /**
   * Cancels the whole game; booker only (AC-06).
   *
   * @param   {string} bookingId The booking id.
   * @param   {string} userId    The signed-in user.
   * @returns {Promise<void>}
   * @throws  {NotFoundException}  Unknown / not Open Play.
   * @throws  {ForbiddenException} Caller is not the booker.
   * @throws  {ConflictException}  Cancelled, started, other players inside cutoff, or lost race.
   */
  async cancel(bookingId: string, userId: string): Promise<void> {
    const booking = await this.loadOpenPlay(bookingId);
    if (booking.userId !== userId) throw new ForbiddenException(MSG.NOT_BOOKER);
    if (booking.isActive !== true) throw new ConflictException(MSG.INACTIVE);

    const now = new Date();
    if (hasStarted(booking.bookDate, now)) {
      throw new ConflictException(MSG.STARTED);
    }

    const outcome = await this.repository.cancelBooking({
      bookingId,
      bookerId: userId,
      now,
    });
    if (outcome.kind === 'OTHER_PLAYERS') {
      throw new ConflictException(MSG.CANCEL_CUTOFF);
    }
    if (outcome.kind === 'NOT_CANCELLABLE') {
      throw new ConflictException(MSG.NO_LONGER_AVAILABLE);
    }
  }

  /**
   * Marks an existing booking Open Play; venue staff only (AC-01).
   *
   * @param   {string}            bookingId The booking id.
   * @param   {string}            userId    The signed-in user.
   * @param   {EnableOpenPlayDto} dto       Optional capacity / public flag.
   * @returns {Promise<OpenPlayManageResponse>}
   * @throws  {NotFoundException}  Unknown booking.
   * @throws  {ForbiddenException} Caller is not staff of the booking's venue.
   * @throws  {ConflictException}  Already Open Play, cancelled, started, no booker, or lost race.
   */
  async enable(
    bookingId: string,
    userId: string,
    dto: EnableOpenPlayDto,
  ): Promise<OpenPlayManageResponse> {
    const booking = await this.repository.findById(bookingId);
    if (!booking) throw new NotFoundException(MSG.BOOKING_NOT_FOUND);
    if (!(await this.isStaff(booking, userId))) {
      throw new ForbiddenException(MSG.STAFF_ONLY);
    }
    if (booking.isOpenPlay) throw new ConflictException(MSG.ALREADY_OPEN_PLAY);
    if (booking.isActive !== true) throw new ConflictException(MSG.INACTIVE);

    const now = new Date();
    if (hasStarted(booking.bookDate, now)) {
      throw new ConflictException(MSG.STARTED);
    }
    if (booking.userId === null) throw new ConflictException(MSG.NO_BOOKER);

    const outcome = await this.repository.enableOpenPlay({
      bookingId,
      now,
      capacity: dto.capacity ?? DEFAULT_OPEN_PLAY_CAPACITY,
      isPublic: dto.isPublic ?? false,
      token: this.tokenHelper.generate(),
    });
    if (outcome.kind === 'NOT_ENABLEABLE') {
      throw new ConflictException(MSG.NO_LONGER_AVAILABLE);
    }
    return this.buildManageView(await this.loadOpenPlay(bookingId));
  }

  /**
   * Toggles public listing; booker or venue staff (AC-02).
   *
   * @param   {string}                   bookingId The booking id.
   * @param   {string}                   userId    The signed-in user.
   * @param   {SetOpenPlayVisibilityDto} dto       The new flag.
   * @returns {Promise<OpenPlayManageResponse>}
   * @throws  {NotFoundException}  Unknown booking.
   * @throws  {ForbiddenException} Neither booker nor venue staff.
   * @throws  {ConflictException}  Not Open Play, cancelled, or lost race.
   */
  async setVisibility(
    bookingId: string,
    userId: string,
    dto: SetOpenPlayVisibilityDto,
  ): Promise<OpenPlayManageResponse> {
    const booking = await this.repository.findById(bookingId);
    if (!booking) throw new NotFoundException(MSG.BOOKING_NOT_FOUND);
    await this.assertCanManage(booking, userId);
    if (!this.isOpenPlay(booking)) throw new ConflictException(MSG.NOT_OPEN_PLAY);
    if (booking.isActive !== true) throw new ConflictException(MSG.INACTIVE);

    const updated = await this.repository.setVisibility(bookingId, dto.isPublic);
    if (!updated) throw new ConflictException(MSG.NO_LONGER_AVAILABLE);

    return this.buildManageView({ ...booking, isOpenPlayPublic: dto.isPublic });
  }

  /**
   * Management read (token + roster names); booker or venue staff.
   *
   * @param   {string} bookingId The booking id.
   * @param   {string} userId    The signed-in user.
   * @returns {Promise<OpenPlayManageResponse>}
   * @throws  {NotFoundException}  Unknown / not Open Play.
   * @throws  {ForbiddenException} Neither booker nor venue staff.
   */
  async getManageView(
    bookingId: string,
    userId: string,
  ): Promise<OpenPlayManageResponse> {
    const booking = await this.loadOpenPlay(bookingId);
    await this.assertCanManage(booking, userId);
    return this.buildManageView(booking);
  }

  private async join(
    booking: OpenPlayRecord,
    userId: string,
    requirePublic: boolean,
  ): Promise<JoinOpenPlayResponse> {
    if (booking.isActive !== true) throw new ConflictException(MSG.INACTIVE);
    const now = new Date();
    if (hasStarted(booking.bookDate, now)) {
      throw new ConflictException(MSG.STARTED);
    }

    const outcome = await this.repository.joinSeat({
      bookingId: booking.id,
      userId,
      now,
      requirePublic,
    });
    switch (outcome.kind) {
      case 'JOINED':
        return {
          bookingId: booking.id,
          confirmedSeats: outcome.confirmedSeats,
          capacity: outcome.capacity,
          isFull: isFull(outcome.confirmedSeats, outcome.capacity),
        };
      case 'FULL':
        throw new ConflictException(MSG.FULL);
      case 'ALREADY_SEATED':
        throw new ConflictException(MSG.ALREADY_SEATED);
      case 'NOT_JOINABLE':
        throw new ConflictException(MSG.NO_LONGER_AVAILABLE);
    }
  }

  private async loadOpenPlay(bookingId: string): Promise<OpenPlayRecord> {
    const booking = await this.repository.findById(bookingId);
    if (!this.isOpenPlay(booking)) throw new NotFoundException(MSG.NOT_FOUND);
    return booking;
  }

  private isOpenPlay(
    booking: OpenPlayBookingRecord | null,
  ): booking is OpenPlayRecord {
    return (
      booking !== null &&
      booking.isOpenPlay &&
      booking.openPlayCapacity !== null &&
      booking.openPlayJoinToken !== null
    );
  }

  private isStaff(
    booking: OpenPlayBookingRecord,
    userId: string,
  ): Promise<boolean> {
    return this.repository.hasVenueStaffMembership(
      userId,
      booking.court.venue.tenantId,
      booking.venueId,
    );
  }

  private async assertCanManage(
    booking: OpenPlayBookingRecord,
    userId: string,
  ): Promise<void> {
    if (booking.userId === userId) return;
    if (await this.isStaff(booking, userId)) return;
    throw new ForbiddenException(MSG.FORBIDDEN_MANAGE);
  }

  private async buildManageView(
    booking: OpenPlayRecord,
  ): Promise<OpenPlayManageResponse> {
    const roster = await this.repository.findRoster(booking.id);
    return {
      listing: this.toListing(booking),
      isPublic: booking.isOpenPlayPublic,
      isActive: booking.isActive === true,
      joinToken: booking.openPlayJoinToken,
      roster: roster.map((seat) => ({
        name: seat.user.name,
        isBooker: seat.isBooker,
        joinedAt: seat.createdAt.toISOString(),
      })),
    };
  }

  /** Explicit field-by-field mapping. Never spread a record here (AC-08). */
  private toListing(record: OpenPlayListingRecord): OpenPlayListing {
    const capacity = record.openPlayCapacity ?? 0;
    const confirmedSeats = record._count.openPlaySeats;
    return {
      id: record.id,
      startsAt: record.bookDate.toISOString(),
      venue: {
        id: record.court.venue.id,
        name: record.court.venue.name,
        slug: record.court.venue.slug,
        city: record.court.venue.city,
      },
      court: { id: record.court.id, name: record.court.name },
      capacity,
      confirmedSeats,
      isFull: isFull(confirmedSeats, capacity),
    };
  }
}
```

```ts
import { isAxiosError } from "axios"

/** Pulls the NestJS `message` out of an Axios error, falling back to a generic line. */
function getApiErrorMessage(
  error: unknown,
  fallback = "Something went wrong. Please try again."
): string {
  if (isAxiosError<{ message?: string | string[] }>(error)) {
    const message = error.response?.data?.message
    if (Array.isArray(message)) return message.join(" ")
    if (typeof message === "string" && message.length > 0) return message
  }
  return fallback
}

export { getApiErrorMessage }
```

```ts
  })
}
```

```ts
/** Converts a `YYYY-MM-DD` picked in the browser to that local day's [from, to) ISO instants. */
function localDayRange(date: string): { from: string; to: string } {
  const start = new Date(`${date}T00:00:00`)
  const end = new Date(start)
  end.setDate(end.getDate() + 1)
  return { from: start.toISOString(), to: end.toISOString() }
}

const startsAtFormatter = new Intl.DateTimeFormat(undefined, {
  weekday: "short",
  month: "short",
  day: "numeric",
  hour: "numeric",
  minute: "2-digit",
})

function formatStartsAt(iso: string): string {
  return startsAtFormatter.format(new Date(iso))
```

```tsx
import { OpenPlayIntro } from "@/components/open-play/open-play-intro"

function OpenPlayPage() {
  const router = useRouter()
  const pathname = usePathname()
  const searchParams = useSearchParams()

  const date = searchParams.get("date") ?? ""
  const venueId = searchParams.get("venueId")
  const venueName = searchParams.get("venueName")
  const page = Math.max(Number(searchParams.get("page") ?? "1") || 1, 1)

  const query = useMemo<ListOpenPlayQuery>(
    () => ({
      page,
      ...(venueId ? { venueId } : {}),
      ...(date ? localDayRange(date) : {}),
    }),
    [date, venueId, page]
  )

  function update(next: Record<string, string | null>) {
    const params = new URLSearchParams(searchParams.toString())
    for (const [key, value] of Object.entries(next)) {
      if (value) params.set(key, value)
      else params.delete(key)
    }
    router.replace(`${pathname}?${params.toString()}`, { scroll: false })
  }

  return (
    <>
      <AuthHeader />
      <main className="bg-background text-foreground min-h-svh pt-16">
        <div className="mx-auto max-w-4xl space-y-8 px-6 py-10">
          <OpenPlayIntro />
          <OpenPlayFilters
            date={date}
            venueName={venueId ? (venueName ?? "Selected venue") : null}
            onDateChange={(value) => update({ date: value || null, page: null })}
            onClearVenue={() => update({ venueId: null, venueName: null, page: null })}
          />
          <OpenPlayList
            query={query}
            onVenueClick={(id, name) => update({ venueId: id, venueName: name, page: null })}
            onPageChange={(next) => update({ page: String(next) })}
          />
        </div>
      </main>

}
```

```tsx
                field.onChange(checked)
                if (!checked) form.setValue("isOpenPlayPublic", false)
              }}
            />
          )}
        />
      </div>

      {isOpenPlay ? (
        <>
          <div className="space-y-1.5">
            <Label htmlFor="open-play-capacity">Players (including you)</Label>
            <Controller
              control={form.control}
              name="openPlayCapacity"
              render={({ field }) => (
                <Input
                  id="open-play-capacity"
                  type="number"
                  inputMode="numeric"
                  min={1}
                  step={1}
                  className="w-28"
                  value={Number.isNaN(field.value) ? "" : field.value}
                  onChange={(event) => field.onChange(event.target.valueAsNumber)}
                  onBlur={field.onBlur}
                  aria-invalid={capacityError ? true : undefined}
                />
              )}
            />
            {capacityError ? (
              <p className="text-destructive text-xs">{capacityError}</p>
            ) : null}
          </div>
          <div className="flex items-center justify-between gap-4">
            <Label htmlFor="open-play-public-create" className="flex-col items-start gap-0.5">
              <span className="text-sm font-medium">List publicly</span>
              <span className="text-muted-foreground text-xs font-normal">
                Off by default. Only people with your invite link can join.
              </span>
            </Label>
            <Controller
              control={form.control}
              name="isOpenPlayPublic"
              render={({ field }) => (
                <Switch
                  id="open-play-public-create"
                  checked={field.value}
                  onCheckedChange={field.onChange}
                />
              )}
            />
          </div>
        </>
      ) : null}
    </div>
  )
}

export { OpenPlayBookingOptions }
```
